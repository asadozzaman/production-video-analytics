# Examples

Reproducible public examples will be added here as the implementation milestones are completed.

Each example must include:

1. A public, licensed, or synthetic input source
2. The exact configuration and model reference
3. Hardware and software environment details
4. Expected output files
5. Accuracy, latency, resource, and cost measurements
6. Known limitations and representative failure cases

Private employer or customer data must never be added to this repository.
